1. Walks through a directory (recursively) and finds every `*.txt` file.  
2. Reads all those files, tokenises the text into words (ignores any punctuation, case‑insensitive).  
3. Counts the word frequencies with `collections.Counter`.  
4. Prints the top‑5 most frequent words (ties are resolved by alphabetical order).  

```python
#!/usr/bin/env python3
"""
Top‑5 word frequency finder

Usage
-----
    python top5_words.py [<directory>]

If no directory is supplied, the current working directory is used.
"""

import sys
import re
from collections import Counter
from pathlib import Path

# --------------------------------------------------------------------------- #
# Helper functions
# --------------------------------------------------------------------------- #

def tokenize(text: str) -> list[str]:
    """
    Convert a string to a list of lower‑case words.
    Words are sequences of Unicode alphabetic characters.
    Non‑alphabetic characters are treated as separators.
    """
    # Replace any non‑letter characters with spaces, then split
    return re.split(r"\s+", re.sub(r"[^\w]", " ", text.lower()))

def read_text(path: Path) -> str:
    """
    Read a file and return its raw text.
    UTF‑8 is used; if a decoding error occurs, we silently ignore the
    problematic parts (fallback to errors='ignore').
    """
    try:
        with path.open("r", encoding="utf-8", errors="ignore") as f:
            return f.read()
    except OSError as e:
        print(f"⚠️  Could not read {path}: {e}", file=sys.stderr)
        return ""

def count_words(root: Path) -> Counter:
    """
    Recursively walk ``root`` and count all words in every .txt file.
    """
    counter = Counter()
    for txt_file in root.rglob("*.txt"):
        raw_text = read_text(txt_file)
        counter.update(tokenize(raw_text))
    return counter

# --------------------------------------------------------------------------- #
# Main logic
# --------------------------------------------------------------------------- #

def main() -> None:
    # Argument handling: directory is the first argument or CWD
    if len(sys.argv) > 2:
        print("Usage: python top5_words.py [<directory>]")
        sys.exit(1)

    directory = Path(sys.argv[1]) if len(sys.argv) == 2 else Path.cwd()
    if not directory.is_dir():
        print(f"❌  {directory} is not a directory.", file=sys.stderr)
        sys.exit(1)

    # Gather frequencies
    counter = count_words(directory)

    # Show top‑5 words
    print("\nTop‑5 words by frequency:")
    for i, (word, freq) in enumerate(counter.most_common(5), 1):
        print(f"  {i}. {word:<15} : {freq}")

if __name__ == "__main__":
    main()
```

### How it works

| Step | What happens |
|------|--------------|
| **Argument parsing** | `sys.argv` contains a directory path or defaults to the current working directory. |
| **File traversal** | `Path.rglob("*.txt")` walks the directory tree *recursively*, yielding every `*.txt` file. |
| **Unicode, encoding** | Files are read with `encoding="utf-8", errors="ignore"` – this keeps the script robust against varying encodings. |
| **Tokenisation** | `re.sub(r"[^\w]", " ", text.lower())` replaces anything that is not a letter, digit, or underscore with spaces, then splits on whitespace. The result is a list of lower‑case words. |
| **Counting** | `collections.Counter` tallies the words; after all files are processed we obtain the global frequency distribution. |
| **Top‑5 output** | `Counter.most_common(5)` returns the five most frequent words (ties are broken arbitrarily by insertion order).  The script prints them nicely. |
