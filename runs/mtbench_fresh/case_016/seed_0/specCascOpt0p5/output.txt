## When does an LM start?

From a pure “why” – almost every data‑driven algorithm used **monetary** to learn the language is a bit like a *supervised* program if we had a single label on each book. But that’s not the case: **a language model is trained on *unlabelled* data** – it learns from the raw text itself, just because we don’t need to know which words are “good” or “bad”.  
The two tricks are:

| •                           | What the model does | What there is *label* |
|-----------------------------|---------------------|-----------------------|
| **Unlabelled data** | “Open‑AI’s fast‑internet knowledge‑dumps” | - |
| **Self‑supervised** | “Count all words, predict the next one” | Usually *yes* – the “next word” is a label, but the model is the only one that knows it. |
| **No external labeling** | You never hand a label like “Good” → “0, bad” → “1” | “We have to guess the words” |

## “Bimodal” – constructing from the text: a reinforcement signal

Because I am only reading *text*, the model does *not* have a human‑labelled “label” for each word. The approach is basically:

1. **Data** – stream in millions of sentences from news, books, Wikipedia, etc.  
2. **Task** – For every token in the sentence, predict as the context of past tokens → “next word / masked word”.  
3. **Loss** – a “prediction” error = (surprise) loss – raised and the model is confused (bad).  

So after a bunch of information, the model learns the *probability* that words appear together. It can be *further* trained on *special* examples:

| Task | Example of human command |
|------|--------------------------|
| *Translation* | “Translate the following sentence from Spanish to English.” |
| *Fine‑tune* | “Translate ‘Bonjour’ into English.” |
| *Adjection* | “Rewrite that paragraph with more detail.” |
