**How it works**

1. The List `jokes` holds the 4 jokes.  
2. The `<button>` listener adds a `click` event to the button.  
3. When the button is clicked, we use `Math.random()` to pick a random index from the jokes array (0-4).  
4. The result shows the joke in the `<div id="joke"></div>`.
