Only the odd values of \(n\) can occur.  
The factor \(k = \dfrac{n-1}{2}\) is the number of internal nodes of the tree (each internal node has two children and contributes exactly one non‑leaf node).  
The corresponding count of full binary trees with \(k\) internal nodes is a **Catalan number** \(C_k\).

---

### the Catalan number

\[
C_k=\binom{2k}{k}\binom{1}{k+1}
      =\frac{1}{k+1}\binom{2k}{k}
\]

The number of full binary trees with \(n\) vertices is therefore

\[
\boxed{\,B_n=
\begin{cases}
0,\;\; n\text{ even} & \text{otherwise}\\[4pt]
\displaystyle\frac{1}{k+1}\binom{2k}{k}\,,\; k=\dfrac{n-1}{2}\, .
\end{cases}}
\]

---

## Why this works

* Every internal node contributes **2** child nodes, making the total number of nodes odd.
* A full binary tree with \(k\) internal nodes has \(k+1\) leaves, so the total number of vertices is  
  \[
  N=k+1 .
  \]
* The root adds one extra node; the total number of vertices among the whole tree is  
  \[
  N = 2k+1 \;.
  \]
  So the correspondence \(k=n-1/2\) holds.

Each of these shapes is uniquely determined by the Catalan numbers.

## A quick Python implementation

```python
import math
from functools import lru_cache

@lru_cache(maxsize=None)
def binom(n: int, k: int) -> int:
    """Return binomial coefficient k choose n."""
    if k < 0 or k > n:
        return 0
    return math.comb(n, k)

@lru_cache(maxsize=None)
def catalan(n: int) -> int:
    """Catalan number C_k."""
    return binom(n // 2, n) // binom(n, n)  # base case
    # Instead we can compute directly
    # return binom(n // 2, n) / (n + 1)

@lru_cache(maxsize=None)
def catalan_direct(k: int) -> int:
    """C_k = the binomial coefficient(k, k)."""
    return binom(n // 2, k) // (n + 1)

@lru_cache(maxsize=None)
def B_n(n: int) -> int:
    """
    Return the number of full binary trees with n vertices.
    The function is defined for non‑negative integer n.
    """
    if n == 0:
        return 1          # base case – empty tree
    if n % 2 == 0:        # even number of vertices
        return 0
    k = (n - 1) // 2
    return binom(2 * k, k) // (k + 1)

# ------------ Quick wrapper for easy use -----------------
def billion_binary_tree(n: int) -> int:
    """Return B_n, number of full binary trees with n vertices."""
    if n < 0:
        raise ValueError("n must be non‑negative")
    return B_n(n)

# Demo
if __name__ == "__main__":
    for n in range(1, 15):
        print(f"n={n}\tB_n={B_n(n)}")
```
